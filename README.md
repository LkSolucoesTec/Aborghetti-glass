## 📖 Sobre o projeto

Website institucional desenvolvido para a **Aborghetti — Soluções Educacionais**, consultoria especializada na criação de experiências de aprendizagem e soluções educacionais corporativas.

O projeto nasceu da proposta de construir uma presença digital contemporânea, combinando comunicação institucional, direção de arte, tecnologia e experiências interativas.

Cada seção foi desenvolvida para transmitir a identidade da empresa, apresentar suas competências e estabelecer uma conexão entre inovação, criatividade e educação.

Mais do que um website institucional, o projeto propõe uma experiência digital visualmente envolvente, com navegação intuitiva e foco na apresentação comercial da marca.

## ✨ Diferenciais do projeto

- Interface personalizada com estética Liquid Glass e Glassmorphism.
- Direção de arte com elementos tridimensionais e iluminação cinematográfica.
- Hero imersiva com partículas interativas em Three.js.
- Animações e transições desenvolvidas em JavaScript Vanilla.
- Navegação com rolagem híbrida.
- Diagrama interativo de conexões profissionais.
- Apresentação dinâmica das oito soluções educacionais.
- Experiência mobile adaptada com cards translúcidos.
- Portfólio com visualizador de imagens e controles de ampliação.
- Carrossel de depoimentos.
- Galeria responsiva de clientes e parceiros.
- Formulário com validação e download de apresentação comercial.
- Integração com WhatsApp.
- Layout responsivo para diferentes dispositivos.

## ⚙️ Executando localmente

Clone o repositório:

    git clone https://github.com/LkSolucoesTec/Aborghetti-glass.git

Acesse a pasta do projeto:

    cd Aborghetti-glass

Abra o projeto no Visual Studio Code e execute utilizando a extensão **Live Server**.

Não é necessário instalar dependências ou executar processos de build.
